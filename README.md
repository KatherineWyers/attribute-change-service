# Attribute Lifecycle Service #
An open-source service for managing identity attribute lifecycle events, verification, 
workflows, versioning, and propogration across Digital Public Infrastructure 
ecosystems including DHIS2, MOSIP, and OpenCRVS.

## Background ##
Built by Dr. Katherine Wyers, software engineer specialising in identity and health
data infrastructure, with a PhD in information systems from the
University of Oslo. Now working as a digital identity and identity data consultant.
